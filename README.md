## What it does

`main.py` writes one original, funny one-line tombstone epitaph — 81 characters,
a single line — deterministically to `/output/entry.txt`.

> Here lies Tom. His last words were 'Hold my beer.' The beer survived. He did not.

## Run

```sh
python3 main.py
```

The program self-checks the gate before writing: UTF-8 text, 1–150 characters,
not only whitespace, single line.
